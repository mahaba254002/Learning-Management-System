# Rollcall frontend

React and Vite interface for the Rollcall learning-management platform. See the [root README](../README.md) for setup, architecture, deployment and verification, and the [user guide](../docs/USER_GUIDE.md) for the four workspaces.

Run `npm ci`, then `npm run dev`. The local API proxy expects FastAPI on port 8000. Run `npm run lint`, `npm run build` and `node --test tests/*.test.js` before submitting changes.
