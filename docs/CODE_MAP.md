## Shared change points

- Routing and role gates: [App.jsx](../frontend/src/App.jsx), [ProtectedRoute.jsx](../frontend/src/routes/ProtectedRoute.jsx), [roleRoutes.js](../frontend/src/routes/roleRoutes.js).
- Requests, CSRF and renewal: [client.js](../frontend/src/api/client.js); fetched-data invalidation: [teachingQueries.js](../frontend/src/pages/teacher/teachingQueries.js). Avoid parallel custom request clients that bypass these controls.
- Sidebar/mobile layout: [DashboardLayout.jsx](../frontend/src/components/layout/DashboardLayout.jsx), its CSS, each role's layout/nav items, and [useAcademicNavigation.js](../frontend/src/hooks/useAcademicNavigation.js). Check both desktop and phone widths.
- API assembly: [main.py](../backend/app/main.py); environment: [config.py](../backend/app/core/config.py); database connection: [session.py](../backend/app/db/session.py); migrations: [env.py](../backend/alembic/env.py).
- Schema changes require a migration, PostgreSQL validation, backup compatibility review and appropriate tenant constraints. Do not fix missing columns by changing models alone.
- Cross-institution access is a security incident: check server scoping and composite foreign keys. Hiding a React button is not authorization.
